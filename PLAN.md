## Соглашения

- Пакет `jarvis`, запуск `python -m jarvis`, консольная команда `jarvis`.
- Конфиг — TOML в `config/`; локальные значения — `config/config.toml` (в gitignore).
- UI не содержит логики движка; общение только через `surfaces/contract.py`.
- Любой внешний сетевой вызов — отдельный capability-флаг, `false` по умолчанию.
- Логи и БД — в `runtime/`.
- Тесты — pytest, конфиг в `pyproject.toml` (`[tool.pytest.ini_options]`).
